# API Testing Portfolio

API test automation against public practice APIs ([DummyJSON](https://dummyjson.com) and [Restful Booker](https://restful-booker.herokuapp.com)).

**Planned contents:**
- Postman collections with positive, negative and boundary tests
- Automated runs with Newman and GitHub Actions
- Bug reports for issues found in the APIs
- Key tests rebuilt in Playwright with TypeScript

🚧 Work in progress: this repo grows as each part is built.
